تصوّر المسار الوظيفي

من أكتوبر 2026 لحد ما تبقى Data / ML Engineer

التواريخ لحد يوليو 2027 مأخوذة من الرودماب نفسها. اللي بعدها تقديرات مبنية على إنك في سنة تالتة وفاضلك سنتين، فاعتبرها اتجاه مش جدول ملزم، وعدّلها كل 3 شهور.

الرحلة مرحلة بمرحلة

  1. المرحلة 1

    تأسيس

    أكتوبر 2026 – يناير 2027أنت هنا
    • Python (CS50P) وLinux وGit، وبعدها SQL وقواعد البيانات العلائقية ونمذجة البيانات.
    • فترة الامتحانات من 27 ديسمبر لـ 22 يناير: الكلية الأولوية، وساعة أو اتنين freeCodeCamp لما تكون فاضي.

    الناتج اللي يتشاف: ريبو GitHub فيه أول 3 مشاريع صغيرة، وكورس يتعدّ "خلّصته" لما يطلع منه مشروع وملخص صفحة.

  2. المرحلة 2

    بناء الأساس التقني

    فبراير – يوليو 2027أنت هنا
    • Meta Database Engineer وDBA وPython مع قواعد البيانات، ثم ETL وAirflow وKafka وData Warehouse وNoSQL وSpark.
    • من مارس 2027 ابدأ التقديم على تدريب صيفي: الـ CV والـ GitHub لازم يكونوا جاهزين قبلها.
    • مشروع Climate Decision يبقى واجهة الـ CV: README قوي ورسمة معمارية.

    الناتج اللي يتشاف: الكابستون النهائي (Airflow + star schema + Docker + dashboard) اللي مجدول يخلص 27 يوليو. لو التدريب بدأ قبلها، اعمل الكابستون بجرعة أخف بالتوازي.

  3. المرحلة 3

    التدريب الأول

    صيف 2027 (تقدير)أنت هنا
    • أي تدريب قريب من الداتا: Data Engineering أو BI أو Analytics. الأهم تشوف شغل حقيقي وفريق حقيقي.
    • لو فيه اختيار، فضّل اللي فيه pipelines وقواعد بيانات على اللي فيه Excel بس.

    الناتج اللي يتشاف: خبرة تتكتب في الـ CV، وشخص يزكّيك.

  4. المرحلة 4

    تخصص وشهادات

    سنة رابعة 2027/2028 (تقدير)أنت هنا
    • شهادة Databricks (Data Engineer) وشهادة Cloud، AWS أو Azure والاختيار لسه مفتوح.
    • تدريب تاني أو شغل part-time مرتبط بالـ DE، بشرط ما يضربش الدراسة.
    • ML يندمج في شغلك: Climate Decision فيه XGBoost أصلًا، فكمّل عليه نشر الموديل ومراقبته (MLOps).

    الناتج اللي يتشاف: شهادتين، مشروع تخرج مصقول، وتجربتين شغل.

  5. المرحلة 5

    التخرج وأول وظيفة

    حوالي 2028 (تقدير)أنت هنا
    • الهدف: Junior Data Engineer أو Analytics Engineer.
    • مكان الشغل (شركة، ستارت أب، remote) قرار لسه مأجل، وده سليم. بس ابدأ تجمع معلومات عنه في سنة رابعة.
  6. المرحلة 6

    بعد 1 – 3 سنين من الشغل

    بعد التخرجأنت هنا
    • تبقى Data Engineer متوسط، وتختار تعمّق في اتجاه من التلاتة تحت.

التفرّع بعد أول سنين شغل

Senior DE / Data Platform

عمق في البنية: orchestration وwarehouses وlakehouse والأداء والتكلفة. مناسب لو بتحب تبني الأساس اللي الناس كلها بتمشي عليه.

الأقرب حاليًا

ML Engineer / MLOps

pipelines للموديلات ونشرها ومراقبتها. بيجمع الـ DE اللي هو مسارك الأساسي مع الـ ML اللي قلت إنه مكمّل ليه.

Data / Tech Lead

قيادة فريق داتا. مناسب لو كملت تحب تقود، وتقود في المنطقة اللي إنت متعمق فيها.

شكل المهارات (T-Shape)

عمق 1: Data Engineering عمق 2: Machine Learning
Python وSQL Cloud Spark وAirflow Databricks Flutter (هواية)

الملوّن عمق، والمفرّغ أفق واسع تعرف منه كفاية، والمنقّط هواية تفضل جنب المسار.

مراجعة كل 3 شهور

عشان ما يجيش وقت وتندم، وعشان الهدف ما يتوهش وسط الشغل، اقعد كل 3 شهور 20 دقيقة وجاوب:

  1. إيه اللي خلّصته وطلع منه ناتج أقدر أوريه لحد؟
  2. إيه اللي بدأته وسبته، وهل لسه محتاجه ولا أشيله من الخطة؟
  3. هل التدريب أو الشغل اللي قدامي لسه في اتجاه الـ DE والـ ML؟
  4. لو مفيش قرار لازم يتاخد دلوقتي، إيه أرخص تجربة أعرف بيها أكتر؟

ثلاث حاجات تحمي الخطة

  • مشاريع قبل شهادات. الشهادات كتير ومتداخلة في الـ SQL والـ Python، فعدّي المكرر بسرعة وركّز على اللي بيطلع منه مشروع.
  • الكلية مش عدو. التقدير بيفرق في التدريب وأول وظيفة، وساعات الرودماب (3–4 يوميًا) ممكن تتعدّل بعد أول شهر لو الواقع مختلف.
  • ناتج أسبوعي يتشاف. كل أسبوع حاجة صغيرة تشتغل أو تتنشر، لأن النتايج المبكرة هي اللي بتخليك مكمّل.
